# Minimal-Homepage

A clean, customizable browser homepage built with HTML, CSS, and JavaScript.

Designed with a minimal futuristic style featuring a dark OLED interface, time-based greetings, sun and moon icons, and a customizable search experience.

## **This is Source Code from it. Now there is a website and you can set it as your default Startpage.**
---

## ✨ Features

- 🖤 OLED-style dark interface
- 🌗 Dark/light mode toggle
- ☀️ Time-based sun and moon icons
- 🌅 Morning, afternoon, evening, and night greetings
- 🕒 Live clock
- 📅 Live date
- 🔍 Google search bar
- 🎞️ Smooth entrance animations
- ⚙️ JSON-based configuration
- 🔤 Adwaita Sans font support
- 🌐 Works as a custom browser homepage

---

# 🚀 Setup

## 1. Clone the repository

```bash
git clone https://github.com/PSANDILYA1440/minimal-homepage.git
```

Enter the project folder:

```bash
cd minimal-homepage
```

---

## 2. Start the local server

Because this homepage uses JavaScript and JSON files, opening `index.html` directly may cause browser security errors.

Start a local server:

```bash
python3 -m http.server 9000
```

Open your browser:

```
http://localhost:9000
```

---

# 🦊 Browser Setup

This homepage can be used with browsers that support custom homepage URLs.

Examples:

- Firefox
- Chromium-based browsers
- Other modern browsers

Set your homepage or new tab page to:

```
http://localhost:9000
```

You can customize it to fit your preferred browser setup.
